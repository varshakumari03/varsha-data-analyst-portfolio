# Varsha Kumari — Data Analyst Portfolio

A responsive dark-themed React portfolio built with Vite.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Deploy to Vercel

- Push this project to a GitHub repository.
- In Vercel, choose **Add New → Project** and import the repository.
- Framework preset: **Vite**.
- Build command: `npm run build`
- Output directory: `dist`
- Deploy.

## Customize

- Edit project descriptions and links in `src/App.jsx`.
- Update skills in the `skills` array in `src/App.jsx`.
- Replace `public/resume.pdf` with your final verified resume PDF (keep the same filename).
- Add individual GitHub repository URLs when the projects are published.

## Accuracy notes

- The included starter resume uses only details shared so far. Review it and add verified phone number, location, certifications, grades and experience before applying.
- The GitHub links on project cards currently point to the GitHub profile because individual repository URLs were not confirmed.
- The customer churn project uses a simulated dataset; do not describe it as real company/customer data.
